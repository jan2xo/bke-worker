# BKE Worker Consumer Adoption

This repository is proving the shared BKE Autonomous Engineering consumer contract without replacing existing BKE Worker product-specific authority.

During this migration, `BKE-WORKER-CANONICAL-PROJECT-EXECUTION-INSTRUCTIONS.md` remains the Worker-specific operating contract. The pinned shared instruction layer adds cross-repository GitHub truth, exact-head evidence, ownership, human-auth, certification-graph, capsule, and evidence-escalation semantics.

Do not delete or weaken existing Worker certification, security, dispatcher, browser-authentication, production, or human-authorization boundaries merely because they are not yet modeled as shared checks.

The adoption is successful only when the consumer repository exact head and the pinned Autonomous Engineering source revision are both verifiable and the declared repository checks execute from this repository root.
