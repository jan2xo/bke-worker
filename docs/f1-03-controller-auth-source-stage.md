# F1-03 controller principal and conservative local fence — source stage

This is a **separate, non-operational source module**, not a native/Chrome controller transport. It does not authenticate a ChatGPT account, OS process, extension, GitHub assignment, or physical browser. It must only be invoked by a future host transport **after the host cryptographically verifies the local P-256 proof on the same native channel**. Do not trust a caller-supplied LOCAL_PROOF_OK shape as that prerequisite.

`native-host/controller-admission.mjs` accepts a short-lived one-shot Ed25519 signature from a genuinely **separately owner-pinned external controller public key**, over a domain-separated challenge containing the extension origin, worker, bridge, profile and target commitments, and both live P-256 nonces. All frame fields are exact-schema checked and effectful commands rejected. No private controller key is generated or loaded by this module.

On verification, four cross-process local reservations are written with O_EXCL, O_NOFOLLOW, private owned parent directory checks and fsync: worker, browser profile, ChatGPT target and bridge. Reservations survive MV3/host process exit and clock expiry. An ambiguous partial write leaves fences blocking rather than releasing. There is **no automatic stale-lock cleanup**; operator recovery needs a separately reviewed procedure with independent physical-identity proof. These hashes only fence matching **locally asserted** commitments; their collision/refusal behavior is not proof that two independently attested actual ChatGPT targets are different or that the controller is globally exclusive.

**Important remaining integration work:** independently reviewed owner/controller key provisioning; real external authenticated transport after verified P-256 host proof; transactionally pin this new host source module during installation; authenticate distinct physical profile/target and GitHub worker/PR assignment; define safe operator recovery after MV3/native process crashes; install/test through an authorized signed Mac operator entrypoint. The current native entry, popup and runtime do not import or execute this module, and no new privilege is reachable. Do not advertise controller admission or a physical PASS based on these tests.
