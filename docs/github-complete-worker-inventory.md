# Complete GitHub App PR inventory adapter (SOURCE ONLY)

Part of BKE Worker's authorized **multi-worker** mission, following [PR #112](https://github.com/jan2xo/bke-worker/pull/112). GitHub is the only durable task/PR ledger. Current single-worker GitHub Actions scheduler remains unchanged and `android-worker-a` only.

`scripts/github_complete_worker_inventory.py` is a **read-only adapter** around an already authenticated GitHub App installation's GitHub REST client. The caller must supply the exact expected repository scope from an independent trusted Admin decision; never infer universe of repositories from a token's *potentially narrowed* accessible-repository list. It performs strict, bounded per-page reads of open PRs in every expected repository **twice**. A missing/inaccessible repository, malformed response, truncated/invalid page, duplicate PR, mismatched base repository, or changed relevant PR set/head/labels across passes fails closed; only a stable double-read emits a `complete: true` observation compatible with PR #112's pure audit. It does not fetch or trust PR body instructions, issue queue state or bearer tokens.

**Limits:** Two matching successive scans are not an atomic multi-repository snapshot or exclusive lease. GitHub can still change after the scan. An adapter result does not establish worker availability, host identity, verified browser/profile registration, permission to assign PRs, or right to send a ChatGPT turn. Those require a separately certified Command Center resource proof and globally serialized, exact-head/label/lease compare-and-swap step. This module MUST NOT be wired into live scheduler until that work is complete; no new GitHub App scope, secondary task DB, Notion, production/PREPRODUCTION, Chrome permissions or Android wake.

Certification: cheap PR Guard with adversarial Python HTTP-stub tests verifying every page, mismatch, duplicate, denial and drift; no substantial CI graph, live mutation or deployment.
